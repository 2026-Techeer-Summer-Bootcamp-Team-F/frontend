# Team-F Frontend

Frontend application for 2026 Techeer Summer Bootcamp Team-F.

## Stack

- Vite
- React
- TypeScript
- React Router DOM
- Axios

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Copy `.env.example` to `.env` and set values as needed.

```text
VITE_API_BASE_URL=
```
